## Leaflet Web Map
## Author: Ashley Teal
## Assignment Description
This assignment uses leaflet to create two interactive maps: Weather and Earthquake Maps. Data is sourced real-time from the National Weather Service and the U.S. Geological Survey (USGS). 
## Weather Map
A map showing real-time weather radar and alerts from the National Weather Service. Weather alerts are colored based on severity.
[View Weather Map] <https://ateal1299.github.io/LeafletWebMapDemo1/Weather/>
## Earthquake Map
A map showing earthquake data and seismic risk pattern. Earthquakes are displayed in varying sizes and colors based on the magnitude. If you click on an earthquake marker, you can find information about the magnitude, location, and time of occurance. A legend is picutred in the bottom right to explain magnitude color coding. 
[View Earthquake Map] <https://ateal1299.github.io/LeafletWebMapDemo1/Earthquake/>
